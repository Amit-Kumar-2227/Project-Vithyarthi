# Agentic Workflow Automation System (Java CLI)

A modular, multi-agent task execution and state-management system built purely in Java. Designed to operate entirely via the command line for automated evaluation and high-performance task routing.

---

## 🚀 Features
* **Multi-Agent Pipeline:** Coordinates distinct agent roles (`Planner`, `Executor`, and `Verifier`) to process complex tasks step-by-step.
* **CLI-Driven Interface:** Fully interactive command-line menu with zero GUI dependencies, optimized for terminal execution.
* **State & Log Management:** Tracks lifecycle states (`PENDING`, `RUNNING`, `COMPLETED`, `FAILED`) and logs execution metrics locally.
* **Robust Exception Handling:** Gracefully handles invalid inputs and runtime edge cases to prevent unexpected crashes.

---

## 🛠️ Prerequisites
Ensure you have the following installed on your system before setup:
* **Java Development Kit (JDK):** Version 17 or higher.
* **Build Tool:** Standard `javac`/`java` compiler or Apache Maven.
